# CutClone — เว็บแอปจำลอง (Clone) ของ CapCut

โปรเจกต์นี้เป็นงานเลียนแบบ (clone) หน้าตาและการทำงานพื้นฐานของแอป CapCut
(หน้ารวมแม่แบบ + หน้าตัดต่อ) โดยสร้างด้วย **HTML, CSS, JavaScript ล้วน**
และทำเป็น **PWA (Progressive Web App)** เพื่อให้สามารถ "เพิ่มลงหน้าจอโฮม"
และใช้งานแบบออฟไลน์ได้บนสมาร์ทโฟน

> ⚠️ นี่คือผลงานเลียนแบบ (clone) เพื่อการเรียนรู้เท่านั้น ไม่ใช่แอป CapCut จริง
> รูปภาพตัวอย่างแม่แบบทั้งหมดสร้างขึ้นเอง ไม่ได้ใช้ภาพบุคคลจริงจากแอปต้นฉบับ

## ฟีเจอร์
- หน้าแรกแบบ Feed แสดงการ์ดแม่แบบ 2 คอลัมน์ พร้อมแท็บหมวดหมู่และช่องค้นหา
- แตะแม่แบบเพื่อเข้าสู่ **หน้าตัดต่อ (Editor)**:
  - ใส่รูปของตัวเอง แล้วลากวางซ้อนบนแม่แบบ
  - เพิ่มข้อความ ปรับสี/ขนาดตัวอักษร
  - เพิ่มสติกเกอร์อีโมจิ
  - ลบเลเยอร์ที่เลือก
- **ส่งออกผลงาน**
  - ส่งออกเป็นรูปภาพ (.png) ดาวน์โหลดได้ทันที
  - ส่งออกเป็นคลิปวิดีโอสั้น (.webm) โดยบันทึกภาพเคลื่อนไหวจาก canvas
  - บันทึกโปรเจกต์ไว้ในเครื่อง (localStorage) ดูย้อนหลังได้ในแท็บ "โปรเจกต์"
- ติดตั้งเป็นแอปบนมือถือได้ (PWA) และเปิดใช้งานแบบออฟไลน์ได้ผ่าน Service Worker

## โครงสร้างไฟล์
```
capcut-clone/
├── index.html      # หน้าเว็บหลัก (ทุกหน้าจอ)
├── style.css       # สไตล์หน้าตาแบบ CapCut
├── app.js          # ตรรกะแอปทั้งหมด + ตัวแก้ไข canvas
├── manifest.json   # ข้อมูลแอปสำหรับ PWA (ชื่อ, ไอคอน, สีธีม)
├── sw.js           # Service Worker สำหรับแคชให้ใช้งานออฟไลน์ได้
└── assets/         # ไอคอนแอปและภาพตัวอย่างแม่แบบ (สร้างขึ้นเอง)
```

## วิธีใช้งาน / ติดตั้งบนมือถือ
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub Pages หรือโฮสต์ไฟล์สถิต (static hosting) ใดก็ได้
2. เปิดลิงก์เว็บไซต์ด้วย Safari (iOS) หรือ Chrome (Android)
3. กด "แชร์" → "เพิ่มไปยังหน้าจอโฮม" (iOS) หรือ "ติดตั้งแอป" (Android)
4. แอปจะเปิดแบบเต็มจอเหมือนแอปทั่วไป และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

## รันทดสอบบนเครื่อง (local)
ต้องรันผ่าน local server (ไม่ใช่เปิดไฟล์ตรงๆ) เพราะ Service Worker ต้องใช้ http/https:
```bash
cd capcut-clone
python3 -m http.server 8080
# แล้วเปิด http://localhost:8080
```

## เทคโนโลยีที่ใช้
- HTML5 / CSS3 / JavaScript (Vanilla, ไม่ใช้ framework)
- Canvas API (วาดและจัดองค์ประกอบภาพ)
- MediaRecorder + captureStream API (ส่งออกวิดีโอจาก canvas)
- localStorage (บันทึกโปรเจกต์)
- Web App Manifest + Service Worker (PWA / ใช้งานออฟไลน์)
